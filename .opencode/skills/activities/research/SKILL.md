# Research

Delegate the reading to a **background agent** so work continues while it
reads. Its job:

1. Investigate the question against **primary sources** — official docs,
   source code, specs, first-party APIs — not secondary write-ups of them,
   and follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save the file where the project keeps such notes; match the existing
   convention, and if there is none, put it somewhere sensible and say where.

## Related skills

- tracking — a question that arises along the way may belong in the
  questions tracker; a ticket's research slice calls this skill and closes
  with a pointer to the notes.
