# Changelog template

If the project generates its changelog with a tool, the tool creates the
file; create nothing.

Otherwise, create `CHANGELOG.md` at the project root:

```markdown
# Changelog

All notable changes to this project are documented in this file.
Format follows Keep a Changelog (<https://keepachangelog.com>); versions follow SemVer.
Versioning — the starting version and who approves each bump — is a ruling
recorded in `conventions/`.

## [Unreleased]

### Added
### Changed
### Deprecated
### Removed
### Fixed
### Security
```
