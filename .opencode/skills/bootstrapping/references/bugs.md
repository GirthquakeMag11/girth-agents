# Bugs tracker — `tracker/BUGS.md`

## Template

Create `tracker/` if needed, then:

```markdown
# BUGS

Bugs the project intends to fix. Entries carry full detail plus a log of
work already done; see the tracking skill for the triage rules and entry
format.

<!-- entries below, newest first, one `##` section each -->
```

## Full bootstrap

Nothing to ask.

## Mid-task default

Same as the template; the tracking skill then guides adding the entry.

Used through the tracking skill, which owns the triage rules, entry format,
and workflow.
