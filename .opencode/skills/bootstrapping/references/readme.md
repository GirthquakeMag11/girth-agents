<!-- The project's current state: stage, what works, what is in flight. -->

<!-- Where the real docs live. -->

## Full bootstrap

Take the name, description, and license from the project where it states
them; ask for whichever it does not, and for the current status.

## Mid-task default

Create the skeleton with what is known. Leave the project name as a
placeholder rather than guessing it.

Used through the maintaining-docs skill, which owns what makes README.md
good and how the project's state is conveyed.
