# Decision records — `decisions/`

## Template

Create the empty `decisions/` directory. Records appear as decisions are
made, one numbered file each; bootstrap writes none of its own. Git does not
track an empty directory, so add a `.gitkeep` if the project should commit
it now.

## Full bootstrap

Ask whether the project already holds decisions worth recording now: choices
that were hard to reverse, would surprise a newcomer, and came from a real
trade-off. Record each one the user names per the domain-modeling skill.

## Mid-task default

Create the directory; a record is added only when a decision is recorded.

Used through the domain-modeling skill, which owns when a decision earns a
record, the format, and numbering.
