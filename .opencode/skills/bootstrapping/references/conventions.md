# Conventions — `conventions/`

## Template

Create the empty `conventions/` directory. `On_<Domain>.md` files appear as
rulings are recorded, never during bootstrap. Git does not track an empty
directory, so add a `.gitkeep` if the project should commit it now.

## Full bootstrap

Ask whether the project already has conventions or rulings worth capturing
now. Record each one the user names per the conventions skill — this is the
one piece whose contents come from the user's own rulings.

## Mid-task default

Create the directory; a domain file is added only when a ruling is recorded.

Used through the conventions skill, which owns what counts as a ruling, file
naming, and the entry format.
