# Tracker template

Create `tracker/` at the project root if needed, then the missing file or
files:

`tracker/HAZARDS.md`

```markdown
# HAZARDS

Expensive lessons are learned once: one entry per obstacle a future agent
will hit again. See the tracker skill for criteria and entry format.

<!-- entries below, newest first, one `##` section each -->
```

`tracker/BUGS.md`

```markdown
# BUGS

Bugs the project intends to fix. Entries carry full detail plus a log of
work already done; see the tracker skill for the entry format.

<!-- entries below, newest first, one `##` section each -->
```

`tracker/DEFECTS.md`

```markdown
# DEFECTS

breaks. See the tracker skill for the boundary with bugs and the entry
format.
```
