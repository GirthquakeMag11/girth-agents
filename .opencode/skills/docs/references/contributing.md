# CONTRIBUTING.md — protocols for a new agent

After reading CONTRIBUTING.md, a new agent understands how content is added
to or changed in the project:

- How to prepare the environment and verify a change — build, test, lint.
- Where the standards bind — `conventions/` — and the tracker protocols:
  where the trackers live and which situations go where.
- Changelog discipline: user-visible changes get an entry in the same
  change.
- How to propose and land a change.
